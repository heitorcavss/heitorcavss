## 🚀 Featured Projects

### 🤖 [TrelloPilot](https://github.com/heitorcavss/Trello-pilot)
AI agent that automates daily task organization and labeling on Trello using natural language commands.
Built with Google Gemini API and Google ADK — creates cards, moves them between lists, and applies labels based on context.
`Python` `Gemini API` `Google ADK` `Trello API` `AI Agents`

### ⚙️ [LinkedIn AI Auto-Post — n8n on Render](https://github.com/heitorcavss/n8n-render)
Autonomous content pipeline that generates and publishes daily IT posts to LinkedIn using an n8n AI agent + Gemini.
Self-hosted on Render (free tier) via Docker, with Postgres persistence on Neon and UptimeRobot keep-alive.
`Docker` `n8n` `Gemini API` `PostgreSQL` `Render` `Automation`

Console-based student management system in Python with full CRUD, grade calculation, filtering, and auto-generated enrollment IDs.
Built as a practical study in Python transition from C/Java, focusing on clean code and modularization.
`Python` `CRUD` `Data Structures`
